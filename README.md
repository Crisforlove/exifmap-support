# ExifMap 支持网站

ExifMap 的英文支持页和隐私政策，托管于 GitHub Pages。

- 首页：`index.html`
- 支持页：`support.html`
- 隐私政策：`privacy.html`
- 样式：`styles.css`

开发者公开署名为 Crisforlove，支持邮箱为 aplstar2001@163.com。

网站仅包含静态 HTML 与 CSS，无第三方字体、脚本、分析、广告或表单。GitHub 的托管处理已在隐私政策中说明。

GitHub Pages 使用 main 分支根目录发布。更新页面后推送到 main，等待 Pages 部署完成，再检查公开页面。

应用新增服务、SDK、收集行为或存储方式时，需要同步更新政策与 App Store 隐私申报。
